# Contributing

Contributions are welcome. Please follow these guidelines.

- Add new entries at the bottom of the most fitting category, or propose a new category.
- Use the format `- [Name](link) - Description.`
- The description starts with a capital letter, ends with a period, and is concise and objective. Avoid marketing language and repeating "yargs".
- Link to the GitHub repository (or the project site), not a registry page.
- Only add packages that extend or directly support yargs, or notable projects that use it. Packages must be actively maintained (a release or meaningful commit in the last year), not archived, and have documentation.
- Check that the link works and the item is not already listed.
- One item per pull request, with a title like `Add Name`.
- Run `npx awesome-lint` before submitting.
- Do not hard-wrap lines.
- Entries are ordered alphabetically within each category, except the Official section.
